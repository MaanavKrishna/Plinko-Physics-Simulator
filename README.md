# Plinko Physics Simulator
Plinko Physics Simulator is an interactive physics-based project inspired by the classic Plinko game. Developed using the p5.js library and Matter.js physics engine, this program simulates the behavior of particles (or “plinko balls”) interacting with divisions, obstacles, and gravity. It’s a fun and educational way to explore physics concepts such as collision, motion, and randomness in an engaging visual format.

Features
	•	Dynamic Particle Simulation: Watch particles drop and bounce off pegs, divisions, and walls, creating realistic and visually appealing interactions.
	•	Customizable Environment: Modify parameters like the number of particles, peg layout, and gravity strength to experiment with different scenarios.
	•	Real-Time Interaction: Users can click or interact with the canvas to generate new particles or modify the simulation dynamically.
	•	Physics-Driven Gameplay: Leveraging the Matter.js engine for accurate collision detection, force application, and movement.
	•	Responsive Design: The canvas adjusts to different screen sizes, ensuring a seamless user experience on various devices.

Technologies Used
	•	p5.js: A creative coding library for rendering visuals and handling interactivity.
	•	Matter.js: A powerful JavaScript library for simulating 2D physics, including collisions, forces, and constraints.
	•	HTML/CSS: For structuring and styling the project.

How to Run
	1.	Clone this repository to your local machine:

git clone https://github.com/MaanavKrishna/PRO-C33.git  


	2.	Navigate to the project folder:

cd PRO-C33  


	3.	Open the index.html file in a web browser to view and interact with the simulation.

File Structure
	•	index.html: The main HTML file that serves as the entry point for the application.
	•	style.css: Contains styling for the project layout and visual design.
	•	sketch.js: The primary JavaScript file containing the core logic for the p5.js simulation.
	•	Ground.js, Divisions.js, Particle.js, Plinko.js: Supporting JavaScript files that define different objects and behaviors in the simulation.
	•	matter.js: The physics library included to handle collisions and movements.
